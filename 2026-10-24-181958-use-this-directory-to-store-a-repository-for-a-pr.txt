  Prototype plan: simplified Claude web app

  Two decisions to confirm

  1. App shell: Vite + React + a small Express server (recommended), or Next.js.
     Your API key has to stay on a server, so the prototype needs some backend
     either way.
     - Vite + Express: two small processes run with one npm run dev. There's
       less framework to work around, it's plain React, and it's easy to throw
       away.
     - Next.js App Router: you get API routes in the same app and it matches
       your usual stack, but it's heavier than a lightweight prototype needs.
  2. Markdown rendering for Claude's replies. I'd add react-markdown +
     remark-gfm. Without them, replies show as plain text, including code
     blocks.

  Subagents: your ~/.claude/agents/ directory is empty, so there's no frontend
  or React subagent to hand this to. Add one if you want the work done that way.
  Otherwise I'll build it directly.

  Stack

  - React 18 + TypeScript + Vite
  - Tailwind + shadcn/ui: Button, Textarea, DropdownMenu, ScrollArea, Avatar,
    Card, Tooltip, Separator
  - lucide-react for icons (shadcn's default)
  - Express + @anthropic-ai/sdk on the server, with the key in .env
    (ANTHROPIC_API_KEY)
  - Mock database: JSON files in server/data/, read and written by a small
    repository module, so it could later be swapped for a real database without
    touching the routes

  Folder layout

  client/
    src/
      components/
        ui/                # shadcn-generated
        sidebar/           # Sidebar, NavItem, ConversationList, UserFooter
        home/              # Greeting, RecentArtifacts
        chat/              # Composer, MessageList, Message
      pages/               # HomePage, ChatPage
      lib/                 # api client, SSE stream parser, greeting helper
      constants/content.ts # all UI strings (nav labels, placeholders, 
  greetings)
      types.ts
  server/
    index.ts               # Express app
    routes/conversations.ts
    services/claude.ts     # SDK call + streaming
    repo/                  # JSON-file read/write
    data/
      conversations.json   # seeded pinned and recent chats
      artifacts.json       # seeded artifact cards
      user.json            # name, plan

  Features in scope

  Sidebar
  - Nav items (New, Search, Projects, Artifacts, Scheduled, Customize, More).
    Only New works. The others are visual placeholders.
  - Pinned and Recents lists, read from conversations.json
  - User footer showing name and plan
  - Collapse toggle

  Home view
  - Greeting by time of day ("Afternoon, Meredith"), with the logo mark
  - Composer: auto-growing textarea; Enter sends, Shift+Enter adds a new line.
    The +, mic and voice buttons are placeholders.
  - Row under the composer: a Project dropdown (placeholder) and a static model
    label ("Opus 5.5 Medium")
  - Recent artifacts: three cards from artifacts.json, using placeholder
    thumbnails

  Chat view (/chat/:id)
  - Sending from the home view creates a conversation, adds it to Recents, then
    goes to the chat view
  - Message list with Claude's reply streamed in as it's written
  - Composer pinned to the bottom
  - Title: first message, truncated (no extra API call)

  Server API
  - GET /api/conversations, GET /api/conversations/:id, GET /api/artifacts, GET 
    /api/user
  - POST /api/conversations/:id/messages: saves the user's message, streams
    Claude's reply back to the browser as it's generated, then saves the
    finished reply

  Claude API settings
  - Model claude-opus-5-5, effort medium, adaptive thinking, streaming
  - Check for refusals, and turn on the server-side fallbacks: "default" option,
    which retries a refused request on another model. I can leave fallbacks off
    if you'd rather keep the API call minimal.

  Out of scope for this pass

  - Login (a single hard-coded user)
  - Search, Projects, Artifacts pages, file attachments, voice
  - Light mode: the theme colors are set up as CSS variables, but I'll only
    style the dark theme
  - Mobile layout polish
  - Tests beyond a typecheck and lint script

  Build order

  1. Scaffold Vite, Tailwind and shadcn. Set dark theme colors to match the
     screenshot.
  2. Server: Express, JSON repository, seed data, conversation routes
  3. Sidebar and home view (static)
  4. Composer, then the chat view with streaming
  5. Pull all strings into content.ts, then do a final pass on lint and types
